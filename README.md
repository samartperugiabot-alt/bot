# ربات تلگرامی دانشجویی پروجا (Perugia Student Bot)

این پروژه یک ربات تلگرامی چندزبانه، مقیاس‌پذیر و امن برای کمک به دانشجویان و مهاجران در شهر پروجا، ایتالیا (با قابلیت گسترش به شهرهای دیگر) است.

## ✨ قابلیت‌ها

- **چندزبانگی:** پشتیبانی کامل از زبان‌های فارسی، انگلیسی و ایتالیایی.
- **مدیریت پروفایل:** ثبت‌نام، مشاهده و حذف کامل اطلاعات توسط کاربر (سازگار با GDPR).
- **مرکز منابع (Resources Hub):** ارائه اطلاعات دسته‌بندی‌شده در مورد زندگی و تحصیل در ایتالیا که محتوای آن از یک ریپازیتوری GitHub خوانده می‌شود.
- **ابزارهای کاربردی:**
    - محاسبه‌گر آموزشی ISEE.
    - نمایش آب و هوای شهرهای مختلف.
    - تبدیل نرخ ارز.
- **قابلیت‌های اجتماعی:**
    - سیستم کامل هم‌اتاقی‌یابی (ثبت و جستجوی آگهی).
    - سیستم اخبار با قابلیت انتشار توسط ادمین.
    - چت زنده و مستقیم با ادمین‌های ربات.
- **آپلود فایل:** قابلیت آپلود امن فایل‌ها توسط کاربران در Google Drive.

## 🛠️ تکنولوژی‌های استفاده شده

- **زبان:** Python 3.11+
- **فریمورک ربات:** `python-telegram-bot` (v20+)
- **وب سرور (وبهوک):** `FastAPI` & `Uvicorn`
- **پایگاه داده:**
    - `Google Sheets` برای داده‌های ساخت‌یافته (کاربران، آگهی‌ها، لاگ‌ها).
    - `Google Drive` برای ذخیره‌سازی فایل‌ها.
- **کش و صف:** `Redis` (سازگار با Upstash).
- **محتوا:** فایل‌های `JSON` در یک ریپازیتوری مجزای GitHub.

## 🚀 راه‌اندازی و استقرار

### ۱. پیش‌نیازها

- Python 3.11 یا بالاتر.
- یک حساب کاربری Redis (مانند Upstash).
- یک حساب Google Cloud با دسترسی به Google Sheets و Google Drive API.
- توکن ربات تلگرام از BotFather.

### ۲. راه‌اندازی محلی (Local Development)

#### الف) کلون کردن پروژه
```bash
git clone <your-repo-url>
cd <project-folder>
```

#### ب) ساخت محیط مجازی و نصب نیازمندی‌ها
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

#### ج) پیکربندی متغیرهای محیطی
فایل `.env.example` را به `.env` کپی کرده و مقادیر آن را با اطلاعات خود پر کنید.
```bash
cp .env.example .env
nano .env  # or use any other text editor
```
**نکات مهم:**
- `GOOGLE_CREDS_BASE64`: باید محتوای فایل JSON اعتبارنامه سرویس اکانت گوگل خود را به صورت Base64 انکود کرده و در این متغیر قرار دهید. می‌توانید از دستور زیر استفاده کنید:
  ```bash
  cat /path/to/your/credentials.json | base64
  ```
- `BASE_URL`: برای تست محلی، می‌توانید از ابزاری مانند `ngrok` برای ایجاد یک تونل امن به `localhost` خود استفاده کنید. `ngrok http 8000` را اجرا کرده و آدرس `https` داده شده را در این متغیر قرار دهید.
- `DATA_REPO_URL`: آدرس `raw` ریپازیتوری GitHub که فایل‌های JSON محتوایی شما در آن قرار دارد.

#### د) اجرای ربات
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
ربات اکنون روی پورت ۸۰۰۰ در حال اجراست و وبهوک آن از طریق آدرس `ngrok` شما در دسترس است.

### ۳. استقرار روی Render (Production)

Render یک پلتفرم عالی برای استقرار این ربات است.

#### الف) ساخت سرویس جدید
- در داشبورد Render، یک **"Web Service"** جدید بسازید و آن را به ریپازیتوری GitHub خود متصل کنید.

#### ب) تنظیمات سرویس
- **Environment:** `Python`
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`

#### ج) افزودن متغیرهای محیطی
- به بخش "Environment" سرویس خود در Render بروید.
- تمام متغیرهای موجود در فایل `.env.example` را به همراه مقادیر واقعی آن‌ها در این بخش اضافه کنید. **از قرار دادن اطلاعات حساس در فایل `.env` در ریپازیتوری خودداری کنید.**
- `BASE_URL` در Render به صورت خودکار آدرس سرویس شما خواهد بود (مثلاً `https://my-bot.onrender.com`).

پس از ذخیره تنظیمات، Render به صورت خودکار پروژه را بیلد و اجرا خواهد کرد. ربات شما اکنون به صورت آنلاین و پایدار در دسترس خواهد بود.
